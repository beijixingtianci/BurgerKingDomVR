# 🍔 BurgerKingDom VR

> VR 汉堡店经营模拟游戏 —— 在虚拟现实中亲手制作汉堡，并管理你的整个餐厅。

---

## 🛠️ 开发环境

- **引擎版本**：Unity 2022.3.62f3 LTS
- **VR 框架**：Meta XR SDK / XR Interaction Toolkit
- **版本控制**：Git + GitHub（配合 Git LFS 管理大型资源）

---

## 🌿 分支策略

| 分支 | 用途 |
|------|------|
| `main` | 稳定发布版本，随时可运行 |
| `develop` | 日常集成分支，所有新功能先合并到这里 |
| `feature/*` | 个人功能开发分支（如 `feature/grill-system`） |

---

## 🚀 如何开始

1. 克隆仓库到本地
2. 使用 **Unity 2022.3.62f3 LTS** 打开项目
3. 切换到 `develop` 分支获取最新开发进度
